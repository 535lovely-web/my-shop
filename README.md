# 모라중앙교회 홈페이지

부산 사상구 모라중앙교회 공식 홈페이지입니다.

🌐 **배포 주소:** https://vibecoding-seven-phi.vercel.app

---

## 페이지 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 메인 홈페이지 |
| `pastor.html` | 담임목사 인사말 페이지 |

---

## 메뉴 구조

```
교회 소개
├── 담임목사 인사말
├── 교회 연혁
├── 섬기는 사람들
├── 예배 안내
└── 찾아오시는 길

설교
└── 주일 오전 예배

양육교육
├── 새가족부
└── 양육과정

다음세대
├── 유치부
├── 유초등부
├── 중고등부
└── 청년부

교회 소식
├── 광고
├── 새가족 소개
├── 교우 소식
├── 선교지 소식
└── 포토앨범
```
